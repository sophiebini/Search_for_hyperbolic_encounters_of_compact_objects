# Search_for_hyperbolic_encounters_of_compact_objects
Notebooks and data to reproduce the analyses I did for the publication "Search for hyperbolic encounters of compact objects in the third LIGO-Virgo-KAGRA observing run", Bini et al, PRD (2024) https://journals.aps.org/prd/abstract/10.1103/PhysRevD.109.042009
This repository contains:
- 'notebook' folder with the notebooks to reproduce the analysese and figure in the paper
- 'data' main results included in the paper
